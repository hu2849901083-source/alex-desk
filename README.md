## 为什么做 Alex Desk

很多 Obsidian 主页越来越像一块“功能展板”：卡片更多、颜色更满、入口更密，打开以后却更难知道自己真正要做什么。

Alex Desk 的出发点恰好相反：

> 主页不应该抢走你的注意力，而应该把注意力交还给文字、记录与思考。

它不试图代替文件管理器、日历或任务插件，也不重复侧边栏已经完成的工作。它只保留每天真正值得看见的内容，并把复杂数据藏在需要时才展开的层级里。

## 它解决什么

| 常见痛点 | Alex Desk 的回应 |
| --- | --- |
| 主页入口过多，打开后反而不知道先做什么 | 只保留问候、封面、核心数据、当日文字和写作热力 |
| 同一种功能在主页和侧边栏重复出现 | 主动避开文件树、传统日历等重复模块 |
| 数据只有数字，不知道来自哪些笔记 | 指标可展开，能追溯到构成数据的具体文件 |
| 窗口变化后文字拥挤、卡片比例失衡 | 响应式布局、固定节奏间距与内容截断 |
| 视觉效果很强，却盖住了正文 | 对比度优先；模糊、阴影和动效只用于建立层级 |
| 仪表盘依赖大量插件和脚本 | 单插件运行，无 Dataview、Templater 或 QuickAdd 依赖 |

## 设计原则

- **克制**：装饰不与内容争夺第一眼。
- **注意力收回**：主页只回答“我现在最值得关注什么”。
- **渐进呈现**：概览先给结论，细节在悬停、展开或点击时出现。
- **真实可追溯**：所有统计直接读取本地仓库，并能回到来源笔记。
- **光影有目的**：毛玻璃、渐变、高斯模糊与悬停动效用于空间感和反馈，不用于堆砌。
- **本地优先**：不上传笔记、不请求远程服务，数据留在你的 Vault。

## 核心体验

### 一张会呼吸的封面

- 多图左右滑动轮播，而非突然切换
- 轮播间隔可自定义
- 底部透明渐变与渐进模糊自然衔接正文
- 悬浮日期玻璃卡片提示来源
- 点击封面直接进入图片所关联的笔记

### 能解释自己的数据

“全库笔记”“全库字数”“本月有效笔记”“本月日记天数”等指标不是孤立数字。展开卡片即可查看构成数据的最近文件与来源，减少看到两个相似数字时的认知冲突。

### 把文字放回中心

- 当日笔记支持 Markdown 渲染
- 显示行数和标题均可自定义
- 内容过长时保持边界，并以渐隐模糊提示仍有下文
- 卡片支持轻微滚动余量，不让正文被边框生硬切断
- “今日关联”补充上下文，但不重复文件浏览功能

### 写作热力，而不是第二个日历

26 周写作热力图弱化日期、强化持续记录：

- 圆角正方形格子随容器等比缩放
- 字数越多，颜色越深
- 悬停有微拟物抬升与阴影反馈
- 可预览日期，点击直达当天笔记
- 最高记录和最近写作均可追溯

### 多种气质，同一套可读性标准

内置昼夜模式与多套配色，包括静谧海蓝、黑白极简、柔粉和阅读色系。切换主题时同步适配文字、边框、背景、热力色阶和玻璃材质，避免“颜色好看但文字看不清”。

## 安装

### 从 GitHub Release 安装

1. 前往 [Releases](https://github.com/hu2849901083-source/alex-desk/releases) 下载最新的 `alex-desk-版本号.zip`。
2. 解压到你的仓库目录：

   ```text
   <你的 Vault>/.obsidian/plugins/alex-desk/
   ```

3. 确认该目录中包含 `main.js`、`manifest.json` 和 `styles.css`。
4. 重启 Obsidian，进入「设置 → 第三方插件」，启用 **Alex Desk**。
5. 通过左侧功能区的主页按钮打开 Alex Desk。

### 使用 BRAT

在 BRAT 中选择 **Add Beta plugin**，填入：

```text
hu2849901083-source/alex-desk
```

## 第一次设置

打开「设置 → Alex Desk」后，你可以调整：

- 称呼、头像与每日提醒
- 封面图片、关联笔记、轮播开关和间隔
- 昼夜模式与配色主题
- 数据模块标题及指标组合
- 当日笔记目录、标题、显示行数
- 热力图标题、统计周期和文字口径

封面图和头像填写的是 **Vault 内部路径**。发布包不会携带作者的私人图片或本地配置。

## 数据口径

为了避免同名指标带来的认知冲突，默认口径如下：

- **全库笔记**：Vault 中参与统计的 Markdown 文件总数
- **全库字数**：上述文件的正文字符累计
- **本月有效笔记**：本月内创建或修改过的参与统计文件
- **本月日记天数**：日记目录中本月存在有效记录的自然日数
- **热力图累计字数 / 写作日**：仅统计设定的日记目录和当前热力周期

指标标题和组合可以在设置中修改。

## 隐私与依赖

- 所有笔记、路径与统计均在 Obsidian 本地处理
- 不发送遥测数据
- 不需要账户或云端 API
- 不依赖其他社区插件
- 配置保存在插件自己的本地数据文件中，该文件不会进入本仓库

## 适合谁

- 想要一个好看但不喧闹的 Obsidian 入口
- 在意注意力分配、信息层级和认知负担
- 希望统计数据能够追溯到原始笔记
- 喜欢 Apple 式克制、光影与细腻动效，但不想牺牲功能性
- 希望开箱可用，又保留足够个性化空间
